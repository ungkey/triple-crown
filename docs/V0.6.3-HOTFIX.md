# v0.6.3 Hotfix

## Fixed

GSD capability install could reject `triple-gstack` with:

```text
runtimeCompat.supported references unknown runtime "claude"
runtimeCompat.notes references unknown runtime "claude"
```

Triple Crown no longer binds third-party feature manifests to a concrete GSD
runtime registry id.

All bundled feature capabilities now use:

```json
"runtimeCompat": {
  "supported": ["*"],
  "unsupported": [],
  "notes": {
    "*": "..."
  }
}
```

Concrete Claude Code / gstack / Superpowers readiness remains an installer/doctor
responsibility.

## Added

- bundled manifest runtimeCompat preflight;
- explicit diagnostic for the old failure signature;
- regression fake-GSD validator that rejects concrete runtime references.

## Upgrade

Re-run the v0.6.3 installer in the same project. No manual cleanup of the failed
v0.6.2 attempt is required.
